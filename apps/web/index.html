HC Scanner is a private document scanning engine powered by OpenDocScan technology. Original source code is licensed under MIT and/or Apache-2.0. See LICENSE-MIT and LICENSE-APACHE for the applicable license terms.

HC Scanner finds the page, straightens it, cleans it up, reads its text, and writes the PDF using code running inside this tab. Your scans are stored in this browser and are never uploaded unless you explicitly save them to HC Cloud.

You do not have to take that on trust. Open your browser's developer tools, switch to the Network tab, and scan a document: after the app itself has loaded, there are no requests.
